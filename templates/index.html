How the Tamper-Proof System Works

A mathematically verifiable pipeline guaranteeing authentic credentials

1. Issuance & Token Generation

Administrator issues a certificate. The system assigns a unique UUIDv4 identity token, generates an embedded QR code, and produces an official PDF credential.

2. SHA-256 Hash Calculation

A 256-bit cryptographic digest of the certificate document is calculated and immutably stored in the SQLite database as an authoritative integrity fingerprint.

3. Instant Tamper Detection

When scanned or verified, the system recalculates the document's hash in real time. If even one single character was altered, the system flags it as TAMPERED.
